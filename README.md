# ⟫⟫⟫ About :  
This project is a simple Library Management System, that enabled us to apply the software modeling concepts covered in the course. The strategic combination of four design patterns—Factory, Command, Facade, and Singleton—facilitated the development of a modular and scalable architecture. Key challenges included managing global state via the Singleton pattern and orchestrating component interactions using the Facade pattern.
